Branding

Logos

Approved logos are in logos/. Prefer: - CAP-logo.png where possible. If you are using it on an A4 sheet, its width should be 7.5 cm. - Logomark.png where you need a square representation of the mark alone.

Never use a grey-scale version of the logo. If you are printing matter without colour, use the corresponding black and white version.

Typography

If you are developing materials that are not covered by existing templates you should start from Corporate Standard and adapt it for your use.

This section outlines the standard formatting and branding conventions for CAP documents. These guidelines ensure consistency, clarity, and a professional presentation across all materials.

Note that legal submissions follow separate templates.

The properties below are defined in styles and components in CAP templates. Do not set these properties manually if a style or component exists.

Sheet Size and Layout

  • Format: A4, portrait
  • Margins:
    • Top: 2 cm
    • Bottom: 1 cm
    • Left: 2 cm
    • Right: 2 cm
  • First-page header:
    • Positioned 1.5 cm from the top
    • Paragraph spacing: 0 cm above and 1 cm below
    • Bottom padding: 0.5 cm
    • Bottom border: 2.25 pt amber (#F5A623)
    • Logo: Left-aligned, 7.5 cm wide and approximately 1.55 cm high
  • First-page footer:
    • Positioned 1 cm from the bottom
    • Top border: 0.5 pt rule grey (#DDDCEA)
    • Top padding: 0.3 cm
    • Text: IBM Plex Mono 7, uppercase, muted (#7A7799)
    • Character spacing: 0.03 cm
    • Paragraph spacing: 0 cm above and below
    • Line spacing: 1.0
  • Subsequent pages:
    • No header
    • Footer positioned 1 cm from the bottom
    • Top border: 0.5 pt rule grey (#DDDCEA)
    • Top padding: 0.2 cm
    • Document title or reference on the left
    • Page number and total page count on the right
    • Footer text: IBM Plex Mono 7, uppercase, muted (#7A7799)
  • Sectioning:
    • Heading 1 begins on a new page
    • Keep headings with the paragraph, table, or component that follows them

CAP documents use three complementary font families:

  • Sans-serif font: IBM Plex Sans Thai
    • Used for titles, Headings 1–3, normal text, labels, and call-out headings
  • Serif font: Source Serif 4
    • Used for quotations, Headings 4–5, table content, call-out body text, and signature values
  • Monospace font: IBM Plex Mono
    • Used for references, metadata, field labels, dates, identifiers, and footer text

Semantic Colours

Use semantic colours consistently and only for their intended meaning.

Swatch Hex Name Used for
  #2B5797 Information foreground Information headlines
  #EDF2FA Information background Declarations, notes, and cross-references
  #2F7A4A Success foreground Success headlines
  #ECF5F0 Success background Confirmations and received documents
  #B26A1F Warning foreground Warning headlines
  #FAF2E8 Warning background Procedural risks and missing evidence
  #C13030 Danger foreground Danger headlines
  #FBEDED Danger background Deadlines, confidentiality flags, and other high-risk conditions

Usage guidance

  • Use ink and paper as the dominant colours.
  • Use indigo for primary hierarchy and key structural elements.
  • Use indigo light for supporting hierarchy, references, and metadata.
  • Use amber sparingly for structural accents, not text.
  • Use muted and body grey for secondary text.
  • Use indigo tint and table grey for restrained background fills.
  • Always pair each semantic foreground colour with its corresponding background colour.
  • Do not mix this palette with superseded values such as #29307D, #F9AD18, or the former semantic palette.

Table Usage

  • Do not allow a table or a section containing a table to wrap awkwardly across a page break.
  • Start the section or table on a new page when necessary.
  • Keep table notes visually attached to their table.
  • Use the Table Notes style immediately below a table where explanation is required.
  • Follow Table Notes with Normal — Air Above, which adds 0.3 cm above the following paragraph.
  • Repeat the header row when a long table continues onto another page.

Call-outs

Use call-outs only when the content has a clear information, success, warning, or danger function.

Each call-out consists of two adjacent paragraphs: a headline followed by body text. Use the paired named styles so that the background, padding, indentation, and next-style behaviour remain intact.

Headline

  • Font: IBM Plex Sans Thai SemiBold
  • Size: 9
  • Case: Uppercase
  • Character spacing: 0.06 cm
  • Spacing: 0 cm above and below
  • Line spacing: 1.15
  • Padding: 0.46 cm at the top, left, and right
  • Left and right indentation: 0.46 cm
  • Colour and background: Use the appropriate semantic pair

Body

  • Font: Source Serif 4
  • Size: 10
  • Colour: Body grey (#4A4766)
  • Spacing: 0 cm above, 0.46 cm below
  • Line spacing: 1.0
  • Padding: 0.46 cm at the left, right, and bottom
  • Left and right indentation: 0.46 cm
  • Background: Use the appropriate semantic background

Keep each call-out together on one page where possible.

Letter-Specific Layout

The letter template uses a table at the top of the document with the following structure:

  1. Recipient and letter information
    • Two equal-width columns
    • Left: Recipient block
    • Right: Delivery channel and reference information
    • Use the Normal style with line spacing 1.0
  2. Spacer
    • One column
    • Height: 1 cm
  3. Reference labels
    • Four equal-width columns
    • Your reference
    • Our reference
    • Contact person
    • Date
    • Use the Signature-table style
  4. Reference values
    • Four equal-width columns aligned with the labels above
    • Use the Signature-table-content style

The letter template also uses:

  • Closing: Normal style, 0.92 cm above and below, with an 8.5 cm left tab
  • Closing name and title: Normal style with an 8.5 cm left tab; use soft line breaks rather than separate paragraphs
  • Address footer: Address-footer style; size 7, muted (#7A7799), 0 cm above and below, line spacing 1.0

Notes

  • Start every document from the approved template for that document type.
  • Use named paragraph, table, call-out, and signature styles rather than manual formatting.
  • Keep the supplied header, logo, footer, page-number fields, and margins unchanged unless a filing requirement specifies otherwise.
  • Maintain consistent spacing, hierarchy, alignment, and colour usage throughout each document.
  • Keep tables, call-outs, and signature blocks intact across page breaks.
  • Check the final document at normal print size for legibility and complete page numbering.
  • Consistency should take precedence over stylistic preference.
